# FindMyPaw — Ingeniería de Software

Busca facilitar reportes de mascotas perdidas y encontradas en Cochabamba, y adopciones responsables a través de albergues.

**Fuera del alcance:** alertas automáticas por zonas, rastreo GPS en tiempo real y compraventa de animales.
## Desarrollo local

```powershell
npm install
npm run dev
npm run build
```
